# Lista de Exercícios: Programação Web I

Repositório destinado à resolução da lista de exercícios sobre **Funções, Callbacks e Closures em JavaScript**.

## Conteúdos Abordados

* **Function Declaration**
* **Function Expression**
* **Arrow Functions** e Retorno Implícito
* **Functions Callbacks** e Execução Assíncrona
* **Hoisting**
* **Closures**

## Estrutura dos Exercícios

As resoluções estão organizadas por questões no arquivo principal da atividade.

### Principais Destaques de Implementação:

* **Questão 1 a 5:** Conceitos fundamentais e sintaxe de funções.
* **Questão 6:** Correção de erro de *hoisting* com `const` / *Arrow Functions*.
* **Questão 7 (`meuForEach`):** Recriação do comportamento do método.
* **Questão 8:** Explicação do código utilizando closure.
* **Questão 9 (`criarContaBancaria`):** Aplicação prática.
* **Questão 10:** Resolução do problema de escopo com `var` em laços usando `let` e *closures*.
